STEP 01

ホームページを作る

ルナ先生からの解説 🌸 ChatGPTでHTML・CSS・JavaScriptのコードを作り、ブラウザーで表示できます。

🖱️ 操作の手順

  1. サイトの目的と対象読者を決めます。
  2. 必要なページとデザインを指定します。
  3. 生成したindex.htmlを保存してブラウザーで開きます。
  4. スマホ表示やリンクの動作を確認します。
📋 そのまま使える質問文

初心者向けの1ページホームページをHTMLとCSSで作ってください。明るい色でスマホにも対応してください。

ここがポイントです♡
STEP 02

GitHub Pagesで公開

ルナ先生からの解説 🌸 静的なWebサイトならGitHub Pagesで公開できます。公開リポジトリに秘密情報を置かないようにしましょう。

🖱️ 操作の手順

  1. GitHubで公開リポジトリを作ります。
  2. index.htmlなどのファイルをアップロードします。
  3. Settings→Pagesでmainと/(root)を指定します。
  4. 表示されたURLを開いて確認します。
📋 そのまま使える質問文

GitHub Pagesでindex.htmlを公開する方法を、画面を見ながら一つずつ教えてください。

ゆっくり進めてね♡
STEP 03

プログラミングを手伝ってもらう

ルナ先生からの解説 🌸 コードの作成だけでなく、エラーの原因調査や修正案の説明にも使えます。

🖱️ 操作の手順

  1. 言語と実行環境を伝えます。
  2. やりたいことを具体的に書きます。
  3. エラーが出たらメッセージを貼ります。
  4. 修正後は必ず自分の環境で動作確認します。
📋 そのまま使える質問文

Python初心者です。CSVの売上データを月別集計するプログラムを、コードの意味も説明しながら作ってください。

便利な使い方です♡
STEP 04

会社のDXを進める

ルナ先生からの解説 🌸 DXは単なるデジタル化ではなく、業務の流れを見直し改善することが大切です。

🖱️ 操作の手順

  1. 困っている業務を洗い出します。
  2. 手間やミスの多い作業から優先順位を付けます。
  3. 小さな試行を行います。
  4. 時間削減や品質改善を測定します。
📋 そのまま使える質問文

従業員20人の会社向けに、低コストで始めるDX計画を3か月分作ってください。

おつかれさまでした♡
